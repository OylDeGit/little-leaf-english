# 🌱 小叶子英语 · Little Leaf English

每天一点，自然生长。适合儿童、亲子陪伴和零基础学习者的英语学习网站。

**在线学习：[https://oyldegit.github.io/little-leaf-english/](https://oyldegit.github.io/little-leaf-english/)**

## v2.0：300 个词，25 个生活主题

保留最初 96 个词条的全部 ID 和 v1 进度格式，新增 204 个带图片、单词音频和英文例句的词条。

主题包括水果、蔬菜、农场、野生动物、食物、饮料、交通、海洋、运动、颜色、小小生物、形状，以及新增的服饰、家居、校园、自然、天气、身体、职业、音乐、数字、城市地点、玩具、工具和心情。

## 学习功能

- 图片词卡、单词点读、收藏、中文显隐和全词库中英文搜索；搜索结果分批显示，避免手机一次渲染大量词卡。
- 跟读模式：单词慢速播放、例句设备语音、最多 15 秒的本地录音回放；支持左右滑动、方向键及翻页按钮。不上传录音，不进行发音评分。
- 听音选图、看图拼写，每轮最多 10 题；选项避免重复图片和同音词义干扰。单词接受常见英美变体，如 gray/grey、airplane/aeroplane、donut/doughnut。
- 练习自动暂存。退出或刷新后，首页可以继续原题，包括已作答状态和反馈，避免重复记分。结算后可以仅重练错题。
- 每日目标与复习队列：先到期词、再随机新词、最后未到期词；今日目标剩余不足 10 次时按剩余次数安排，达标后可自由练习。
- 答对后按 1/3/7/14/30 天复习，答错后 10 分钟复习；未到期重复答对不提高复习等级，也不推迟原到期时间。
- 收藏复习、成长记录、7 日练习图表与连续学习天数。
- JSON 备份导出、校验及合并导入：每词保留较新记录、每日次数取较大值、收藏合并；设置以当前设备为准。

## 手机与离线体验

主要学习操作使用至少 44px 的触屏区域；拼写输入字号不低于 16px，适配安全区、短屏及键盘遮挡。练习时隐藏底部主导航，提供顶部退出和跟读底部操作。

图片按需加载，音频点击后加载，不再把所有媒体嵌入首屏 JavaScript。设置中下载离线内容后，全部 300 词的图片和单词音频可断网使用；例句语音是否离线可用取决于设备。浏览器支持时可以添加到主屏幕。

学习进度只保存在当前浏览器，不会自动同步。请定期导出备份，换设备后导入。录音只在当前页面保留，离开页面即释放。

## 本地开发与验证

需要 Node.js 22+ 和 Python 3，无需第三方运行依赖或 API Key。

```sh
npm test            # 核心行为、旧进度兼容、300 词资源、题目和暂存校验
npm run build      # 生成 dist/，检查完整媒体与版本化模块依赖
npm run dev        # 构建后在 http://localhost:4173 预览
```

`vocabulary.js` 保存词库内容；`assets/images/` 和 `assets/audio/` 保存原始单词资源；`media.js` 保存资源索引。仅维护词库时保留已有 ID，避免丢失进度关联。

新增词条并准备资源时，可在 macOS 上运行 `npm run prepare:assets`。该辅助脚本使用公开的 Twemoji 插图和系统 Samantha 语音（需 `say`/`afconvert`），会复用已有资源；其他系统可手动放入对应 SVG 和 M4A 文件。日常开发、测试、构建、部署不需要 macOS。

## 自动发布

GitHub Pages 的 Source 设为 **GitHub Actions**。`.github/workflows/pages.yml` 在 main 推送后自动运行测试、构建并部署 `dist/`；PR 只测试和构建。验证失败时不会发布新版本。

构建会给所有模块依赖和 CSS 添加同一发布版本号，给媒体生成内容哈希文件名，并生成离线清单。Service Worker 分开保存页面代码与媒体，重新联网时验证页面资源，避免长时间停留在旧版本。在线打开一次新版本后，新代码即可缓存；新词的完整离线资源可在设置中补充下载。

## 验证范围

自动测试覆盖 300 词资源完整性、96 个原始 ID 保留、复习间隔、重复练习规则、备份合并与无效数据拒绝、全库题目选项、每日目标及练习暂存。构建额外检查模块版本、媒体路径、离线清单和 Service Worker。

浏览器模拟检查覆盖小屏手机、常见手机与平板，包含搜索、完整十题练习、错题重练、刷新续接及关闭预览服务器后的离线使用。真实 iOS/Android 软键盘、扬声器和麦克风体验仍需真机验证。
