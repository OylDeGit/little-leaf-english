# 🌱 小叶子英语 · Little Leaf English

每天一点，自然生长。为儿童、亲子陪伴及零基础学习者设计的响应式英语学习网站。

**在线使用：https://oyldegit.github.io/little-leaf-english/**

## 已有功能

- 12 个生活主题、96 个中英词条与原创英文例句：水果、蔬菜、农场、野生动物、食物、饮料、交通、海洋、运动、颜色、昆虫、形状。
- 图片词卡、点击播放、收藏、搜索、中文显隐、未探索/已巩固筛选。
- 单词跟读：内置美式系统语音音频，慢速可选；麦克风录音及本地回放，最多 15 秒。不上传录音，不进行发音评分。
- 听音选图、看图拼写，每题有反馈，防止重复作答。
- 每日目标与智能练习队列；到期词优先于新词，之后安排未到期的薄弱词。
- 答对后间隔 1/3/7/14/30 天复习，答错后 10 分钟复习；连续 3 级以上显示已巩固。
- 收藏复习、成长记录、7 日学习图表、连续学习天数。
- 浏览器本地进度保存，JSON 导出/合并导入；校验备份内容并保留每个词较新的记录。设备间不自动同步。
- Service Worker 离线下载：设置中主动下载完成后可离线使用图片及单词音频。初次访问需要联网。
- 手机、平板、桌面布局；系统支持时可通过浏览器菜单添加到主屏幕。

## 使用

```sh
npm run dev
# http://localhost:4173
npm test
npm run build
```

插图和音频集中内嵌在 `asset-bundle.js`，无需外部 CDN；备份不包含媒体文件。

无第三方 JavaScript 运行依赖，无需 API Key 或服务器。Node.js 20+ 用于测试与构建；Python 3 用于本地预览。`dist/` 是构建产物；源码根目录也可直接静态托管。

## GitHub Pages

仓库设置 → Pages → Deploy from a branch → `main` → `/(root)`。每次推送 main 后由 GitHub Pages 自动发布。`.nojekyll` 避免额外模板处理。所有资源使用相对地址，可在项目子路径下工作。

## 数据与隐私

学习数据仅存在当前浏览器的 localStorage。清理浏览器数据会丢失进度，请定期导出 JSON。导入保留原有较新的单词记录、每日次数取较大值，收藏合并；学习设置以当前设备为准。不含广告、分析跟踪或账户系统。托管服务仍会处理常规 HTTP 访问。

录音需 HTTPS 或 localhost，并由使用者主动点击、授权麦克风。切换学习界面后释放录音。不同手机、浏览器与系统的录音、音频和 PWA 安装能力存在差异。例句为文本学习材料。

## 验证

`npm test` 验证词库资源完整性、复习间隔、队列优先级、备份合并、畸形备份拒绝、连续学习与离线清单。发布前另检查手机布局、词卡、跟读、听音答题、拼写、保存和离线下载。模拟浏览器验证不能代替真实 iOS/Android 麦克风和扬声器测试。
